# 학교시설 치트키 · SCHOOL FACILITY CHEAT KEY

> **삽질 Zero, 업무 Hero**
> 교육(지원)청 학교시설 업무 담당자를 위한 실무 레퍼런스 — 매뉴얼 · 프로세스 · 판단 기준 · 산출 도구를 한 곳에서.

공문 뒤지기 전에, 선배한테 묻기 전에 열어보는 웹 치트키입니다.
별도 설치·서버 없이 브라우저에서 바로 열리는 정적 HTML로 만들어졌습니다.

---

## 바로 열기

| 페이지 | 설명 |
| --- | --- |
| `index.html` (= `intro.html`) | 진입 랜딩 페이지 |

## 무엇이 들어 있나

### 업무 레퍼런스 (`bible_notion.html`)

기획 → 설계 → 계약 → 시공 → 준공까지 실제 업무 순서 그대로 정리했습니다.

- **제1~5장** 기획 · 설계 · 계약 · 시공 · 준공 단계별 절차와 판단 기준
- **제6장 교육시설안전** 안전점검 · 인증 · 안전성평가 · 문자메시지 모음
- **제7장 매뉴얼 및 지침** 매뉴얼·가이드 8종, 지침 7종 원문 요약

전체 검색과 해시태그 색인을 지원합니다.

### 산출 도구

| 도구 | 용도 |
| --- | --- |
| 얼마니 · 소요예산 대시보드 | 면적·연장·체적 기준 개략 소요예산 |
| 추산이 · 개략공사비 | 초기 단계 공사비 추산 |
| 설계용역비 산출 | 설계용역 대가 (BF인증·손해배상보험료 포함) |
| 공사기간 산출 | 적정 공사기간 가이드라인 기준 |
| 간단내역서 / 일위대가 / 표준품셈 / 단가검색 | 내역 작성 지원 |
| 정산이 · 준공정산 | 준공 정산 점검 |
| 감리발주 방식 | 감리·건설사업관리 발주 방식 판단 |
| 문서자동생성기 | 규정 기반 문서 초안 생성 (오프라인 동작) |

### 그래프뷰 자료실

문서 사이의 연결을 지도처럼 탐색합니다. 하나를 찾으면 관련 문서가 따라옵니다.

## ⚠️ 이용 시 유의사항

**본 자료는 참고용입니다.**

- 실제 업무 적용 전 반드시 **관련 법령·지침 원문과 소속 기관 기준을 확인**하시기 바랍니다.
- 법령·고시·단가는 개정되므로 **최신 여부를 별도로 확인**해야 합니다.
- 산출 도구의 결과는 **개략 추정치**이며, 확정 예산·계약 금액의 근거로 사용할 수 없습니다.
- 본 자료 이용으로 발생한 결과에 대해 제작자는 책임지지 않습니다.
