# 요약 대기함 (inbox)

요약문서로 만들 **매뉴얼·지침·고시 PDF를 이 폴더에 올리면** 자동으로 처리됩니다.

1. GitHub 웹에서 `inbox/` → **Add file → Upload files** 로 PDF 업로드 (휴대폰도 가능)
2. 매일 예약 작업이 PDF를 발견하면 `bible-summary` 규격(A4 1장)으로 요약문서를 만들고
3. 원문 PDF는 `manuals/번호_주제.pdf` 로 옮기고, 요약문서는 `manuals/번호_주제_요약.html` 로 저장
4. 허브(bible.html) 카드 등록 → 옵시디언 볼트 노트 생성 → 사이트 배포까지 자동으로 이어집니다.

파일명 앞에 `[지침]` 또는 `[가이드]` 를 붙이면 분류가 지정됩니다(생략 시 자동 판단).
처리가 끝난 PDF는 이 폴더에서 사라지고, 결과는 `reports/` 에 기록됩니다.
