환경관리비의 산출기준 — 핵심 요약

건설기술 진흥법 제66조 · 시행규칙 제61조 · 「건설공사 환경관리비의 산출기준」(국토교통부 고시)

발주청 = 학교·교육청 — 설계단계에서 환경보전비를 제비율표 요율로 별도 계상할 의무를 지며, 수급인(계약상대자)은 사용내역서를 작성·보관하고 공사감독자가 목적 외 사용 여부를 확인한다. 미계상·미집행은 시정명령·과태료 대상이다.
1구성
환경관리비 = ① 환경보전비 + ② 폐기물처리비
  • 환경보전비 — 공사 중 발생하는 소음·진동·비산먼지·수질오염 등을 방지하기 위한 비용 (설계서에 별도 계상 의무)
  • 폐기물처리비 — 건설폐기물의 수집·운반·중간처리·최종처분 비용 (「건설폐기물의 재활용촉진에 관한 법률」)
2환경보전비 산출
환경보전비 = 대상액 × 요율
  • 대상액 = 재료비 + 직접노무비 + 직접공사비에 포함된 관급자재비
  • 공종별 요율 적용 (아래 표)
  • 산출액이 실제 소요액보다 부족하면 실비 계상 가능
  • 설계변경·물가변동 시 재계상
3공종별 요율(예시)
공종요율(%)
건축공사0.3 ~ 0.5
토목공사0.5 ~ 1.0
조경·기타(전문·개보수)0.3
주택(재건축)0.3

※ 실제 요율은 발주청 제비율 요율표(연도별 고시)에 따름

4폐기물처리비 산출
  • 철거·해체 물량 산출 → 품목별 발생량 원단위 적용
  • 수집·운반비 + 중간처리비(파쇄·선별) + 최종처분비(매립·소각)
  • 혼합폐기물은 단가가 높으므로 분리배출로 절감
  • 지정폐기물(석면 등)은 별도 단가·별도 계상
5사용·정산 관리
  • 목적 외 사용 금지 — 환경보전 용도로만 집행
  • 수급인은 사용내역서를 작성·보관, 발주청이 확인
  • 정산 시 실제 집행액 기준 정산 대상
  • 미계상·미집행 시 시정명령·과태료 대상
6실무 체크포인트
  • 설계 단계에서 환경보전비를 제비율표 요율로 반드시 별도 계상 (누락 빈번)
  • 폐기물처리비는 물량 산출근거(발생량 원단위)를 설계서에 첨부
  • 석면 함유 자재가 있으면 석면조사·지정폐기물 처리비를 별도 반영
  • 공사 중 실제 소요가 계상액을 초과하면 설계변경으로 증액 가능
7핵심 수치 재확인
환경관리비 환경보전비 + 폐기물처리비환경보전비 대상액 × 요율대상액 재료비+직접노무비+관급자재비건축공사 0.3~0.5%토목공사 0.5~1.0%조경·전문·개보수 0.3%주택(재건축) 0.3%부족 시 실비 계상변경 시 재계상정산 실제 집행액 기준
CORE
환경관리비는 환경보전비(요율 계상)와 폐기물처리비(물량 산출)로 나뉜다. 설계 시 누락이 잦으므로 제비율표 요율로 반드시 별도 계상하고, 폐기물은 발생량 원단위 산출근거를 설계서에 첨부하며, 준공 시 실제 집행액 기준으로 정산한다.
