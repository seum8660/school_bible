CEMS(건설엔지니어링 관리시스템) 운영요령 ① — 개요·등재범위·신청방법

실적 입력 및 승인 업무 매뉴얼(발주기관용) ｜ 건설기술 진흥법 제26·30조, 같은 법 시행령 제3·45조 등 ｜ 한국건설엔지니어링협회(2026.1.16.)

1 · CEMS 개요 및 등재 효과
  • 발주기관(인허가기관)이 실적정보를 입력·확인(등록)하면 입찰참가(PQ) 및 업무중첩도 등 증빙자료(실적증명서 등)로 인정
  • 발주청은 계약체결·변경·준공 시 10일 이내 국토교통부장관에게 통보 의무(법 제30조②)
  • 건설사업관리 수행 시 건축법 공사감리·주택법 감리를 한 것으로 간주(법 제42조)
  • 등재자격 — 법 제26조에 따라 등록한 건설엔지니어링사업자(법 제2조8호)
2 · CEMS 입력 대상 및 발주청 범위
  • ①건설기술진흥법령 건설엔지니어링 ②건축법령 다중이용 건축물 감리
  • ③주택법령 공동주택 공사감리 ④건축·주택법령 (민간)건설사업관리
  • 발주청 — 국가·지자체·공기업·준정부기관 및 시행령 제3조 8개 호 기관(출연기관, 위탁시행자 등)
  • 300세대 이상 주택건설공사는 건설엔지니어링사업자만 감리자 지정 가능(주택법 시행령 제47조①)
3 · 신청 및 회원가입 절차
홈페이지 접속(www.cems.kr) → 회원가입 클릭 → 이용약관 동의·사용자분류 "발주처" 선택 → 본인인증 → 회원등록정보 입력·승인요청 → 관리자 승인 후 이용 CEMS는 안정적 활용을 위해 크롬(Chrome) 브라우저 사용을 권장함
  1. ①이용약관 동의 및 사용자 분류를 "발주처"로 선택
  2. ②개인정보보호·고유식별정보처리 동의 후 인증방법(핸드폰인증 또는 I-PIN) 선택·인증
  3. ③회원등록정보 입력 후 승인요청 → 관리자 승인 후 이용 가능
  4. ④이직·부서이동 시 로그인 후 MY PAGE에서 사업담당·계약담당 정보만 변경
4 · 회원가입 유의사항
  • 회원가입은 한 차례만 가능하며 가입 시 ID·PW 반드시 기억
  • 중복 회원가입 시 실적 등 계약 현황 관리에 문제 발생 가능
  • 담당자는 개인자격으로 가입하며 회사대표ID와는 별도로 운용
  • 발주청 담당자 미가입 시, 우선 회원가입을 통해 등록 후 작성 가능
5 · 실적정보 신규작성 개시
  • 신규작성 메뉴 — "건설엔지니어링 정보관리" 탭 "발주청 용역 실적 현황 리스트"
  • 최초 신규작성은 계약담당자만 작성 가능
  • 사업담당자에게 알림(안내문)이 뜨면 확인 후 작성
  • 사업계약 1건 = 실적입력 1건, 저장 후 '용역명' 클릭하여 수정
6 · 핵심 수치 재확인
시스템 URL www.cems.kr 계약체결·준공 통보 10일 이내(국토부) 회원가입 1회만 가능 사용자분류 발주처 선택 최초 신규작성 계약담당자 전용 등재자격 법 제26조 등록 사업자

본 요약은 「CEMS 운영요령(발주기관용) 실적 입력 및 승인 업무 매뉴얼」(한국건설엔지니어링협회, 2026.1.16.)에 근거함.

CEMS(건설엔지니어링 관리시스템) 운영요령 ② — 용역기본정보·입찰계약정보

실적정보 입력(필수 등재 항목) ｜ 용역기본정보·입찰계약정보 작성 기준 ｜ 한국건설엔지니어링협회(2026.1.16.)

1 · 용역기본정보
  • 용역명 입력 후 중복체크 필수(동일 용역 등재 여부 확인)
  • 이행방식 — 단독·공동·분담·혼합 4가지, 방식별 입력절차 상이
  • 분담·혼합은 참여사가 별도 신규작성 후 사업책임기술인이 승인요청
  • 부문은 8개 항목 중 연관성 높은 것 선택, 해당없으면 "기타"
2 · 용역종류
  • 용역분야 — 재정(공공정책) · 민자(민간투자사업) · 민간(순수민간자본)
  • 대분류 — 부문이 건축이면 건설사업관리·감리, 그 외는 건설사업관리·설계등
  • 사업단계 — 설계전단계·시공단계·시공후단계 중 선택
  • 세부분야 — 용역명(사업명)과 반드시 유관한 항목 선택
3 · 용역개요·발주기관정보 입력 절차
위치·개요(사업규모)·공종 입력 → 발주기관 검색·선택 → 사업담당자/계약담당자 각각 검색·선택 → 계약담당자가 용역계약현황 입력 → 사업담당자가 사업개요·참여기술인현황 입력·저장 사업담당자 정보 미등록(미가입) 시 발주청 담당자 회원가입을 통한 등록이 선행되어야 함
  1. ①공종은 여러 개를 수행하더라도 주된 대표 공종 1개만 선택·입력
  2. ②사업담당자/계약담당자 세팅 후 저장 시 입력된 담당자만 실적을 수정 가능
  3. ③해당 담당자는 최초 저장 이후에도 수정 가능
  4. ④담당자별 요청사항은 "사업담당자 요청사항 입력"으로 메시지 전달·확인 가능
4 · 전체용역기간
  • 계약일·착수일 — 용역계약서 기준으로 입력
  • 준공예정일은 필히 기재, 준공일 입력 후 승인을 거쳐야 준공처리
  • 공사기간 — 착수일부터 준공일까지 기산 일자
  • 중지일·재개일 — 여러 차례인 경우 마지막 중지·재개일만 입력
5 · 용역금액
  • 전기·통신·소방 등 타법 관리 분야는 제외하고 산정
  • 예정가격(입찰공고 기준) · 최초계약금액(계약서 명기금액)
  • 준공(예정)금액 — 최초계약금액과 동일 입력 후 준공정산 시 정정
  • 낙찰률 — 예정가격 대비 투찰금액 비율(경쟁입찰 수주 시)
6 · 핵심 수치 재확인
대표공종 1개만 선택 준공예정일 필히 기재 대가산정방식 공사비요율·실비정액가산 등 계약방식 총액·장기계속계약·계속비 주계약업체 지분율 단독 100% 공사개요 시공단계 건설사업관리·감리만 생성 총공사비 관급자재비 포함, 보상비 제외

차수별 용역기간·용역금액, 수주업체 지분, 공사개요, 변경사항 입력 세부사항은 원문 13~20면 참조.

CEMS(건설엔지니어링 관리시스템) 운영요령 ③ — 참여기술인정보·기타정보

필수·선택 등재 항목 ｜ 참여기술인정보·용역일반정보·기성실적·하도급용역현황 ｜ 한국건설엔지니어링협회(2026.1.16.)

1 · 사업 책임기술인
  • 해당 용역을 총괄하는 기술인, 성명·생년월일·회사명 자동입력
  • 성명 클릭 시 팝업창에서 참여기간·직무분야 등 추가입력
  • 발주청 사업담당자 ID로는 '책임기술인'란만 입력
  • 실적 입력 자체는 사업담당자·계약담당자 ID로 로그인 후 진행
2 · 분야별 책임·참여·실무기술인
  • 추가버튼으로 기술인 검색·입력, 또는 엑셀 일괄입력(예제양식 다운로드 후 업로드)
  • 설계등용역은 기술인 검색이 안 되는 경우 임의 입력 가능
  • 공사종류에 해당하는 기술인의 '직무분야'에 따른 '전문분야'를 반드시 확인 후 입력
  • 엑셀 업로드 후에도 개별 기술인 정보의 정확한 등재 여부 반드시 확인
3 · 실적 등재 대상 항목 체계
필수 등재: 용역기본정보 + 입찰계약정보 + 참여기술인정보 → 선택 등재: 용역일반정보 + 용역세부정보 + 기성실적현황 + 하도급용역현황 필수 항목은 모든 용역에 공통 적용, 선택 항목은 등재 필요성 판단에 따라 입력
  1. ①용역기본정보 — 모든 용역 공통 필수, 사업명·용역종류·용역개요·발주기관
  2. ②입찰계약정보 — 모든 용역 공통 필수, 용역기간·용역금액·수주업체
  3. ③참여기술인정보 — 모든 용역 공통 필수, 참여한 건설기술인 현황
  4. ④선택 항목은 반드시 등재할 필요는 없으나 필요시 등재
4 · 용역일반정보·용역세부정보
  • "용역기본정보"의 부문에 따라 입력창 변경(도로·항만·철도·공항·수자원·상수도·하수도·국토도시·건축·플랜트)
  • 전문분야 별로 입력내용이 상이하며, 실제 계약서·세부내역서 상 내용을 입력
  • 건축 부문은 용역세부정보 해당사항 없음(입력 탭 미생성)
  • 선택 항목이므로 필요하다고 판단되는 항목만 등재
5 · 기성실적현황·하도급용역현황
  • 기성실적현황 — 입찰계약정보의 차수별 기간·금액을 기반으로 구성
  • 차수별·회수별 기성금액 입력 시 상단에 전체 합산 금액 표기
  • 하도급용역현황 — 업체가 '하도급 실적' 등재 후 원도급 실적과 연계
  • 발주기관 입력창은 비활성화되며, 실제 하도급 시 업체에 등록 통보 의무
6 · 핵심 수치 재확인
필수 등재 3개 항목 선택 등재 4개 항목 기술인 입력 검색 또는 엑셀 일괄 전문분야 확인 공사종류·직무분야 일치 필수 건축 세부정보 입력탭 없음 참여기술인 첨부파일 용역계약서 동일

직무분야·전문분야·직책·기술등급·공사종류 코드값 전체 목록은 시스템 내 코드표(원문 25~28면) 참조.

CEMS(건설엔지니어링 관리시스템) 운영요령 ④ — 실적 정보의 변경 및 승인 방법

신규·변경 승인 절차 ｜ 건설사업관리계획 연계(건진법 제39조의2) ｜ 한국건설엔지니어링협회(2026.1.16.)

1 · 실적의 신규 및 변경 승인
  • 등재된 건설엔지니어링 사업은 준공 이후에도 변경 가능
  • 변경 사유를 '변경내용'에 기재하고 저장 후 승인절차 진행
  • 승인완료 즉시 "건설엔지니어링 실적확인서 및 업무중복도 현황"에 반영
  • 사업담당자·계약담당자를 겸임하는 경우 승인 클릭 시 바로 승인 완료
2 · 담당자별 승인요청 대상
  • 용역기본정보·참여기술인정보·입찰계약정보 수정 시 — 사업담당 및 계약담당 각각 승인요청
  • 참여기술인정보만 수정 시 — 사업담당 승인요청
  • 입찰계약정보 또는 기성실적현황 수정 시 — 계약담당 승인요청
  • 계약담당자가 먼저 신규입력 시 사업담당자에게, 그 반대도 메시지 자동 전송
3 · 건설사업관리계획 연계 승인 절차
실적 승인 화면 → 계획 제출여부 선택(제출/미제출/예외대상) → 사유·계획자료 입력 → 실적 승인 시공단계 건설사업관리에 해당하면 계획 수립·제출 여부 확인 및 실적 연계가 반드시 필요(건진법 제39조의2)
  1. ①계획자료 CEMS 제출: "제출" 선택 → 해당 발주기관 계획 목록 검색·선택 → 연계 승인(1건의 계획은 1건의 실적과만 연동, 중복연결 불가)
  2. ②계획 미수립·미제출: "미제출" 선택 → 경고 확인 후 승인 가능(단, 국토교통부에 계획 미수립 통보 조치)
  3. ③계획수립 예외대상: "예외대상" 선택 → 예외대상 사유 필히 기재(공란 불가) 후 승인
  4. ④계획 미제출 후 사후 제출 시 협회 담당자에게 유선 연락(02-3460-8646) 후 반드시 연계
4 · G2B 연계 확인
  • 건진법 시행령 제45조⑦에 따라 조달청 G2B 계약정보가 연계되어 발주청 실적 목록에 자동 조회
  • 등재자 목록이 "G2B"인데 승인목록에 "계약완료"로만 있는 경우, 즉시 해당 업체에 실적정보 등재·승인요청 연락
  • 1건 등재·승인요청에는 발주기관(사업·계약담당자)ID와 사업책임기술인ID가 필수
  • 업체가 업무중복도 회피 목적으로 계약내용을 고의 방치하는 사례 유의
5 · 실적 등재·승인 절차도

  • 승인완료 즉시 CEMS를 통해 건설엔지니어링 실적확인서에 반영
  • 보완요청 시(관리자→업체) 보완내용 수정 후 책임기술인ID로 재승인요청
