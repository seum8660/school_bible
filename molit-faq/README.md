# 질의회신 검색 — 학교시설 치트키 연결 안내

국토교통부 자주찾는민원 질의회신 11,821건을 검색하는 단독 웹페이지입니다.
서버나 API 키가 필요 없고, 파일 세 개만 올리면 동작합니다.

## 파일 구성

| 파일 | 크기 | 설명 |
|---|---|---|
| `index.html` | 24 KB | 화면과 검색 기능 전체 |
| `data.bin` | 3.3 MB | 회신 11,821건 (gzip 압축) |
| `opinions.json` | 29 KB | 주제별 질의답변 의견 14개 |

세 파일은 **반드시 같은 폴더**에 있어야 합니다. `index.html`이 나머지 둘을 상대경로로 부릅니다.

## 치트키 저장소에 넣는 방법

1. 치트키 저장소에 `molit-faq` 폴더를 새로 만드십시오.
2. 그 안에 위 세 파일을 올리십시오.
3. 주소는 아래와 같이 됩니다.

```
https://seum8660.github.io/<저장소이름>/molit-faq/
```

4. 치트키 대시보드에서 그 주소로 링크를 거십시오.

폴더 이름은 바꾸셔도 됩니다. 주소만 그에 맞춰 바꾸면 됩니다.

## 동작 방식

- **검색** — 제목에 6점, 질의·회신 본문에 2점을 주고, 검색어의 낱말이 몇 개나 걸렸는지를 곱해 순위를 매깁니다. 세 글자 이상 한글은 끝 글자를 뗀 형태로도 찾으므로 조사가 붙어도 걸립니다.
- **분야 선택** — 상단에서 건축·도로·주택 등을 고르면 그 분야에서만 찾습니다. 여러 개를 함께 고를 수 있고, 선택은 브라우저에 기억됩니다. 고르지 않으면 전체에서 찾습니다.
- **질의답변 의견** — 검색어가 주제 키워드에 걸리면 미리 작성해 둔 의견이 결과 아래에 붙습니다. 모델을 호출하지 않으므로 비용이 들지 않고 항상 같은 내용이 나옵니다.
- **원문** — 질의와 회신은 수집본 그대로 보여 줍니다. 요약하거나 자르지 않습니다.
- **검색 이력** — 브라우저에 저장되며 서버로 나가지 않습니다.

## 주의할 점

- 자료 기준일은 **2026. 9. 14.** 입니다. 그 이후 국토교통부가 올리거나 고친 회신은 들어 있지 않습니다.
- 질의회신은 개별 사안에 대한 행정 회신이며 법적 구속력이 있는 유권해석이 아닙니다.
- 회신일자가 오래된 건은 조문이 개정되었을 수 있습니다. 인용 전에 현행 조문을 확인하셔야 합니다.
- 회신 본문이 비어 있는 건이 30건 있습니다. 원본 게시물 자체가 비어 있는 것으로 보입니다.

## 자료를 새로 받았을 때

수집 스크립트(`molit_faq_all.py`)로 최신본을 받으신 뒤 `data.bin`만 새로 만들어 덮어쓰면 됩니다.

```python
from openpyxl import load_workbook
import json, gzip

wb = load_workbook("국토부_민원마당_질의회신_전체.xlsx", read_only=True, data_only=True)
ws = wb[wb.sheetnames[0]]
it = ws.iter_rows(values_only=True)
hdr = [str(h or "") for h in next(it)]
I = {h: i for i, h in enumerate(hdr)}
KEYS = ["번호", "제목", "카테고리", "담당기관", "담당부서", "등록일자", "질의내용", "회신내용"]

def restore(v):
    s = "" if v is None else str(v)
    return s.replace("_x000D_\n", "\n").replace("_x000D_", "\n").replace("\r\n", "\n").replace("\r", "\n")

rows = [[restore(r[I[k]]) for k in KEYS] for r in it]
with gzip.open("data.bin", "wb", compresslevel=9) as f:
    f.write(json.dumps(rows, ensure_ascii=False, separators=(",", ":")).encode())
print(f"{len(rows):,}건 저장")
```

`index.html`의 맨 위 스크립트에서 `FETCHED_AT` 값을 새 조회일자로 고치는 것도 잊지 마십시오.

## 주제별 의견을 고칠 때

`opinions.json`을 직접 여시면 됩니다. 한 주제는 이렇게 생겼습니다.

```json
{
  "id": "design-change",
  "title": "설계변경과 계약금액 조정",
  "keywords": ["설계변경", "계약금액", "변경계약"],
  "opinion": "본문. 근거는 [#10728] 처럼 표기합니다.",
  "refs": ["10728", "9421"]
}
```

- `keywords` — 이 낱말이 검색어에 들어 있으면 의견이 붙습니다. 자주 쓰시는 표현을 추가하시면 됩니다.
- `opinion` — `[#번호]` 형식으로 쓰면 화면에서 누를 수 있는 링크가 되고, 누르면 그 회신 원문이 열립니다.
- `refs` — 의견 아래에 목록으로 표시할 회신 번호입니다.
