# 워크플로우 세부버전 규격 (카드 1건 → 미니 보드)

bible 매뉴얼/절차 카드 **1건**(예: VE, 안전관리계획서)을 워크플로우 대시보드 문법으로 펼친 "세부버전" 레이아웃.
전체 보드(`WORKFLOW-SPEC.md`)와 달리 **단일 카드용**이며, `templates/워크플로우_세부버전_템플릿.html`을 복사해 내용만 바꾼다.
완성 예시: `Canvas-4.dc.html`의 1a (설계의 경제성 검토 VE).

## 화면 구조 (위→아래 고정)
1. **헤더** — kick `PROCESS BOARD / 근거법령` → 제목(Barlow Condensed 34px) → 한 줄 설명 → 우측 "기준 법령"
2. **통계 5칸** — 대상 요건 / 절차 노드 / 단계 게이트 / 병목 구간 / 결재 단계
3. **범례 1행** — 선행 · 핵심 · 병목 · 후속 · 업무 순서
4. **대상·요건 패널** — 좌측 3px 네이비(#1d2d3d) 보더, 배경 #f8fafc.
   제목: "대상 · 요건 — 하나라도 해당하면 ○○ 실시". 요건은 ①②③ 번호 + 3단 그리드.
   금액·비율 강조만 레드(#c0392b). 보드의 첫 노드는 "위 요건 ①~③ 해당 여부 확인"으로 참조만.
5. **미니 보드** — 그리드 `110px + 4레인 + 72px`. 단계 3~4개(S0~S3), 노드 4~6개.
   레인은 실제 업무 흐름 순서(예: 발주청 담당팀 / 설계사 / 검토조직 / 전결권자).
6. **실시시기·횟수 등 부속 기준** — 회색 박스 1줄 (보드에 다 못 담는 조건 명시)
7. **결재 경로 / 근거 법령 · 지침** — 2단, 좌측 3px #5980a6 보더 소제목
8. **각주** — "※ 본 워크플로우는 실무 참고용입니다…" 유지

## 노드 색 (전체 보드와 동일)
| 종류 | 배경 | 상단선 |
|---|---|---|
| 선행 | #fff | 3px #b5d9fd |
| 핵심 | #eef6ff | 3px #5980a6 |
| 병목 | #d6ebff | 6px #1d2d3d |
| 후속 | #fff | 1px rgba(29,31,32,.3) |

측면·하단 테두리 없음. 노드 내부: id(Barlow 12.5px) + 종류 배지(우측) + 본문 12.5px + 근거 10.5px.

## 화살표 (직각 엘보 — 필수)
- 곡선(bezier) 금지. **직각**만 사용.
- 같은 행: 수평 직선 (a 우측 중앙 → b 좌측 중앙, 끝 -3px).
- 다음 행: a 하단 중앙 ↓ 중간 높이 → 가로 → b 상단 중앙 ↓ (`M ax,ay L ax,my L bx,my L bx,by-3`, my=(ay+by)/2).
- 선: #5980a6 1.6px + marker 화살촉. 노드에 `data-node="n01"…` 부여, SVG는 보드 위 absolute 오버레이.
- **움직이는 점**: 경로마다 `<circle r=3.2 fill=#0075de>` + `<animateMotion dur=2.2s repeatCount=indefinite begin=i*0.55s>`.
- 폰트 로드로 레이아웃이 밀리므로 draw()를 mount 직후 + 400ms + 1200ms 재실행, resize 시 재계산.
- 같은 행에서 노드가 있는 칸을 관통하는 연결 금지 (전체 보드 규칙과 동일).

## 작성 원칙
- 원본 카드의 내용(대상·요건, 실시시기, 결재 경로·상향 기준, 근거 법령·지침, 해시태그)은 **빠짐없이** 배치한다.
- 하단 팝업(상세바)은 만들지 않는다 — 모든 정보를 지면에 노출.
- 폰트: Pretendard + Barlow Condensed(헤더·숫자·노드 id).
