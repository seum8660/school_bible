# 워크플로우 대시보드 규격 (SCHOOL BIBLE)

새 워크플로우는 `templates/워크플로우_대시보드_템플릿.html`을 복사해
**데이터 3개(STAGES · NODES · EDGES)와 헤더·레인 라벨만** 바꾼다. CSS·draw()·패널 스크립트는 손대지 않는다.

## 파일명
`워크플로우_<주제>_대시보드.html` (예: 워크플로우_감리방식_대시보드.html)

## 화면 구조 (고정)
1. **헤더** — `PROCESS BOARD / 근거법령` → 제목(Barlow Condensed 34px) → 한 줄 설명 → 우측 "기준 법령"
2. **통계 5칸** — 절차 노드 / 행위 레인 / 단계 게이트 / 병목 구간 / 회귀 경로
3. **범례 2행** — 1행 선행·핵심·병목 / 2행 후속·업무 순서(실선)·회귀(점선)
4. **보드** — 단일 그리드 `132px + 4레인 + 96px`(회귀선 우회 여백)
   - 레인 구분 실선, 단계 구분 점선, 헤더 하단 진한 실선
   - 셀 패딩 `16px 20px` (화살표 여유 확보 — 줄이지 말 것)
5. **각주** — 참고용 안내 문구
6. **상세바** — 단독 실행은 화면 하단 고정, 임베드는 부모로 postMessage

## 노드 색상 (설계변경 대시보드 기준)
| 종류 | 배경 | 상단선 |
|---|---|---|
| 선행 lead | #fff | 3px `#b5d9fd` |
| 핵심 key | `#eef6ff` | 3px `#5980a6` |
| 병목 bot | `#d6ebff` | 6px `#1d2d3d` |
| 후속 post | #fff | 1px 회색 |

측면·하단 테두리 없음. 배지는 배경 없는 텍스트.

## 데이터 규격

```js
STAGES = [{k:'S0', n:'사유 발생'}, ...]      // 5~6단계

NODES = [{
  id:'N01', s:0, l:'own',        // s=단계 index, l=레인 키
  k:'lead',                      // lead 선행 | key 핵심 | bot 병목 | post 후속
  t:'카드 본문 한 줄', law:'시행령 제75조',
  title:'상세 제목', lane:'S0 사유 발생 · 발주청 담당팀',
  chips:['산출물1','산출물2'], due:'사유 발생 즉시', conf:'90%',
  bottle:'병목 사유',            // k==='bot'일 때만
  lawT:'법적 근거 실무 요지'
}]

EDGES = [['N01','N02'], ['N07','N06',1]]   // 세 번째 값 1 = 회귀(회색 점선)
```

## 레인 배치 — 화살표 가독성 규칙 (중요)
- 레인 순서는 **실제 업무가 흐르는 순서**로 정한다. 주제마다 다르며 고정이 아니다.
  - 설계변경·공기연장: 시공사 / CM·감리 / 발주청 담당팀 / 전결권자
  - 감리방식 결정: 발주청 담당팀 / 용역사 / 기술검토·심의 / 전결권자
- **같은 행에서 두 칸 이상 건너뛰는 연결은 만들지 않는다** — 중간 칸에 노드가 있으면 선이 카드를 관통한다.
  건너뛰게 되면 레인 순서를 바꾸거나 노드를 다음 단계로 옮긴다.
- 정방향은 중심선 위 6px, 회귀는 아래 12px로 분리되어 있다(겹치면 양방향 화살표처럼 보임).
- 배치 후 반드시 카드 관통 여부를 실측 확인한다.

## 작성 원칙
- 노드 12~16개, 병목 3~4개, 회귀 2~3개.
- `lawT`는 조문 제목을 단정하지 말고 **실무 요지**로 쓴다.
- 확신도(conf)는 절차 확실성 체감치 — 병목일수록 낮게(60~75%).
- 각주의 "참고용" 문구는 반드시 유지한다.

## bible_notion 연결
워크플로우 탭 `.wf-picker`에 버튼 추가:
- 활성: `data-src="워크플로우_<주제>_대시보드.html"`, 실선 테두리
- 준비 중: `data-soon="1"`, 점선 + opacity .6

카드 클릭 → 부모의 `__wfDetailBar`(화면 하단 고정)로 상세 표시.
iframe은 **고정 높이 2350px**. 자동 높이 조정 스크립트는 넣지 않는다(런어웨이 발생).
