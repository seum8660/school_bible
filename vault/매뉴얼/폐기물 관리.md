# 폐기물 관리

> 업무편람 4-18 · 시기별 이행사항 · 주체별 역할 · 건설폐기물 처리 흐름도


업무편람 4-18 폐기물 관리 ｜ 시기 구분: 발생 예상 시 → 반출 당일 → 반출 종료 → 처리용역 준공 시 ｜ 관련 주체: 공사 현장대리인(현장소장) · 용역 현장대리인 · 감독관 · 폐기물처리 용역업체

> 감독관 = 공인계근의 실시·입회·검증 주체 — 반출 당일 현장에 도착해 사진을 촬영하고, **임의 1대를 선정**하여 공인계근을 실시하며 계근 전표를 관리한다. 용역 현장대리인은 반출 전 사전보고와 **계근 동행** 의무를 지며, 불가피하게 동행하지 못할 경우 반드시 사전보고하여야 한다.

## 1. 폐기물 발생 예상 시

- **반출 협조요청** — 공사 현장대리인 → 용역업체로 반출 협조를 요청
- **사전보고** — 용역 현장대리인 → 감독관에게 반출계획을 보고
- **보고내용 3항목** — 반출일자 · 반출시간 · 덤프 대수
- ※ 반출 일정이 확정되어야 감독관의 계근 입회 일정을 잡을 수 있으므로 사전보고가 절차의 출발점임

## 2. 반출 당일 · 공사 현장소장

- **폐기물 인계대장**(서식) 작성·제출 — 즉시 처리
- **인계·인수 전표 서명** — 덤프 1대마다 서명. 2장 중 1장은 현장 보관, 1장은 용역업체 보관
- **전표 물량 기입** — 폐기물 물량을 기입하되, 계근 중 수치가 아니라면 개략적으로 기입
- **상차 사진 촬영** — 상차 시 차량마다 차량번호가 나오게 촬영
- ※ 상주 감독이 아니라면 모든 사진을 찍을 수 없으므로, 현장소장의 촬영분이 실질적 증빙이 됨

## 3. 반출 당일 · 감독관 수행사항 — 공인계근 5단계

1. **현장 도착 후 사진촬영** — 반출 현장 상황과 상차 상태를 기록으로 남긴다
2. **공인계근 실시** — 반출 차량 중 임의 1대를 선정하여 감독자가 지정한 공인계량소에서 계근한다(매 반출 시마다 1대 임의선정)
3. **계근 전표 관리** — 공인계근 결과 전표를 감독관이 직접 수령·보관하여 처리대장 대조의 기준으로 삼는다
4. **공인계근 장면 사진 촬영** — 계근이 실제로 이루어졌음을 입증할 수 있도록 계근하는 장면을 촬영한다
5. **용역 현장대리인 동행** — 계근 시 용역 현장대리인이 동행한다. 불가피할 경우 사전보고를 거쳐야 한다

## 4. 반출 종료 · 용역 현장대리인

- **폐기물 처리대장**(서식) 작성·제출 — 17:00까지
- ※ 처리가 일찍 종료될 경우 정리 후 바로 제출
- **올바로 시스템 입력** — 당일 처리분을 시스템에 입력

## 5. 반출 종료 · 감독관

- **물량 대조** — 용역업체가 작성한 처리대장과 공인계근 물량을 비교
- **시스템 확인** — 올바로 시스템 입력 여부 확인
- **내부 보고** — 당일 폐기물 처리내용을 내부 보고

# 폐기물 관리 ② — 건설폐기물 처리 흐름도

업무편람 4-18 폐기물 처리 흐름도 ｜ 계약 → 처리계획서 제출 → 성상별 보관 → 공차계근 → 운반 → 계근 → 중간처리업체 반입 → 자체계근 → 파쇄·선별 → 순환골재 생산

> 감독자 = 공인계량소 지정 주체 — 공차계근과 계근은 모두 **감독자가 지정한 공인계량소**에서 실시하며, **매 반출 시마다 1대를 임의 선정**한다. 업체가 계량소를 임의로 정하거나 차량을 특정할 수 없다는 점이 이 흐름도의 핵심 통제장치이다.

## 1. 건설폐기물 처리 흐름 10단계

1. **계약** — 폐기물처리 용역 계약 체결
2. **건설폐기물 처리계획서 제출** — 제출처는 관할 지자체. 신고필증 교부 3일 이내
3. **건설폐기물 발생** — 폐콘크리트 · 건설폐재류 · 폐아스콘 · 혼합건설폐기물. 성상별로 분리한 후 현장 보관
4. **공차계근** — 감독자가 지정한 공인계량소에서 실시. 매 반출 시마다 1대 임의선정
5. **건설폐기물 운반** — ☑ 전용차량 및 허가받은 임시차량만 사용 가능
6. **계근**(적차) — 감독자가 지정한 공인계량소에서 실시. 매 반출 시마다 1대 임의선정
7. **중간처리업체 폐기물 반입** — 건설폐기물 중간처리업체로 반입. ☑ 검교정 확인서 확인
8. **계근(자체계근)** — 중간처리업체의 자체 계량설비로 반입량 계근
9. **파쇄 및 선별** — 반입된 건설폐기물을 파쇄·선별 처리
10. **순환골재 생산** — 최종적으로 순환골재를 생산하여 재활용

## 2. 건설폐기물 성상 4종

- **폐콘크리트** — 구조체 철거·해체에서 발생
- **건설폐재류** — 폐벽돌·폐블록 등 무기성 폐재
- **폐아스콘** — 포장 절삭·철거에서 발생
- **혼합건설폐기물** — 성상 분리가 되지 않은 혼합물
- ※ 성상별로 분리한 후 현장에 보관하는 것이 원칙 — 혼합 보관 시 혼합건설폐기물로 처리되어 처리비가 상승함

## 3. 계근 3단계 체계

- **① 공차계근** — 상차 전 빈 차량 중량. 감독자 지정 공인계량소
- **② 계근(적차)** — 상차 후 중량. 감독자 지정 공인계량소
- **③ 자체계근** — 중간처리업체 반입 시 업체 자체 계량
- ※ ①·②는 매 반출 시마다 1대를 임의 선정하여 실시하며, 그 전표를 감독관이 관리한다
- ※ ③의 전표는 준공서류에 차량마다 일체 첨부하여 대조 근거로 삼는다

## 4. 흐름 단계별 확인 서류

- **처리계획서 · 신고필증** — 관할 지자체 제출, 3일 이내 교부
- **인계·인수 전표** — 덤프마다 서명, 2장 분산 보관
- **공인계근 전표** — 감독관이 직접 관리
- **검교정 확인서** — 중간처리업체 반입 단계에서 확인
- **폐기물 인계대장 · 처리대장** — 반출 당일 · 반출 종료 시 각각 제출
- **올바로 시스템 출력물** — 준공 시 인쇄 제출

## 5. 감독 유의사항 — 흐름도 체크(☑) 항목

- **운반차량 자격** — 전용차량 및 허가받은 임시차량에 한함. 미허가 차량 투입 여부를 반출 당일 확인
- **계량설비 신뢰성** — 중간처리업체 반입 시 검교정 확인서로 계량설비의 유효성을 확인
- **계량소 지정권** — 공인계량소는 감독자가 지정하며 업체가 선택하지 않는다
- **차량 임의선정** — 계근 대상 차량은 사전에 알리지 않고 반출 시마다 임의 선정
- **사진 증빙** — 상차 시 차량번호 · 공인계근 장면을 각각 촬영하여 보관

## 6. 핵심 수치 재확인

**신고필증 교부** 3일 이내
**처리 흐름** 10단계
**건설폐기물 성상** 4종
**계근 체계** 3단계 (공차 · 적차 · 자체)
**공인계근** 매 반출 1대
**운반차량** 전용 · 허가 임시차량
**반입 확인** 검교정 확인서

한 줄 결론

폐기물 관리의 실질은 **물량 검증**이므로, 감독관이 **지정 공인계량소에서 매 반출 1대를 임의 계근**하고 그 전표를 직접 관리한 뒤 준공 시 **처리대장 · 올바로시스템 · 업체 계근 전표**를 3중 대조하는 것이 절차의 핵심이며, 사전보고와 사진 증빙이 이를 뒷받침한다.
