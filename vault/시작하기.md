# 학교시설업무 치트키 볼트

이 볼트는 치트키 사이트(https://seum8660.github.io/school_bible/)에서 **자동으로 생성**됩니다.

- 사이트에 요약문서·워크플로우가 추가되면 GitHub Actions가 노트를 다시 만들어 저장소에 올립니다.
- `generated: school_bible` 표시가 있는 노트는 자동 생성 노트라서 **다음 갱신 때 덮어써집니다.**
- 직접 쓰는 메모는 `내 노트/` 폴더에 두세요. 자동 갱신이 절대 건드리지 않습니다.
- 매뉴얼 전체 목록은 [[_매뉴얼 색인]], 전체 흐름은 [[학교시설업무 치트키]]에서 시작하세요.
