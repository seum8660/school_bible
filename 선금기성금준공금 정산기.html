학교시설 공사 계약관리 도구 · 금액은 입력값 기준 자동 계산이며 지급 전 계약서·관련 규정으로 확인하세요

공사계약지급 보고서

내역서부터 준공 정산까지 한 곳에서 관리할 수 있어요

사용 설명서 테스트용

공사 1건을 등록하고 계약부터 준공 정산까지 단계별로 입력합니다

처음 시작하기

  1. 공사 등록「+ 새 공사」 또는 「예시 공사 추가」로 입력 예시 확인
  2. 공사 개요전체 현황 탭에서 공사명·계약일·착공일·준공예정일 입력
  3. 단계별 입력상단 단계 탭을 왼쪽부터 차례로 채움
  4. 점검·내보내기전체 현황의 점검 사항 확인 후 엑셀로 내보내기

단계별 입력 방법

공사내역서설계금액(원가계산서)과 계약금액(착공내역서)을 비목별로 입력합니다. 낙찰률과 비목별 비율이 자동 계산됩니다.
선급금선금률을 넣으면 선금액이 천원 미만 절사로 계산됩니다. 지급 여부를 「지급 완료」로 바꿔야 이후 기성·준공에서 선금 정산이 시작됩니다.
노무비월별 청구액·지급액을 입력합니다. 지급한 노무비는 다음 기성 회차의 노무비 공제 칸에 넣어 이중 지급을 막습니다(새 회차 추가 시 미공제분이 자동 입력).
기성금회차별 청구일·검사완료일·기성액을 입력하면 선금 정산액, 실지급액, 지급기한(영업일 기준)이 계산됩니다. 선금 정산 누계가 100%가 되는 회차는 선금 잔액 전액을 정산합니다.
설계변경회차별 증감액(감액은 −)과 공기 증감일수를 입력합니다. 변경계약금액과 변경 준공예정일에 반영됩니다.
하도급 직불하수급인과 하도급 금액을 등록하면 기성 회차마다 직불액을 입력할 수 있습니다. 직불액은 계약상대자 실지급액에서 빠지고, 하도급 금액을 넘으면 점검 사항에 표시됩니다.
물가변동조정기준일·방식·등락률을 입력합니다. 적용대가를 비우면 조정기준일 이전 기성을 뺀 금액으로 자동 계산하고, 90일 경과·등락률 3% 이상 요건을 판정합니다.
정산(준공금)준공일·지체일수·지체상금률을 입력합니다. 준공 기성액에서 선금 잔액·미공제 노무비·지체상금을 뺀 준공 지급액이 계산됩니다.

입력 요령

  • 금액 칸은 숫자만 입력하면 됩니다. 쉼표는 자동으로 붙습니다. Enter를 누르거나 다른 칸을 누르면 반영됩니다.
  • 파란색으로 강조된 칸은 자동 계산 결과입니다. 직접 입력 칸(선금액, 적용대가, 준공 노무비 공제)은 비워두면 자동값을 씁니다.
  • 행 삭제는 「삭제」를 누른 뒤 「확인」을 한 번 더 눌러야 지워집니다.
  • 각 단계 아래 계산 예시에 현재 입력값으로 된 산식이 표시되니 지급 결의 때 근거로 옮겨 적을 수 있습니다.
  • 전체 현황의 검산 줄이 「변경계약금액과 일치」로 나오면 지급 내역이 맞게 입력된 것입니다.

저장

  • 입력하면 자동 저장됩니다. 우측 상단에 저장 상태가 표시됩니다.
  • 「이 브라우저에만 임시 보관 중」으로 표시되면 같은 PC·같은 브라우저에서만 다시 볼 수 있습니다.
  • 파일 저장: 현재 공사를 .json 파일로 내려받습니다. 다른 PC에서 불러오기로 열면 입력값이 그대로 복원됩니다(새 공사로 추가).
  • 엑셀 내보내기: 보고·결재용 엑셀(.xlsx)을 만듭니다. 엑셀 파일은 다시 불러올 수 없으니 보관용은 파일 저장을 쓰세요.

테스트용 도구입니다. 계산 로직을 검증 중이므로 실제 지급·정산 문서에 그대로 쓰지 마시고, 결과가 다르면 알려 주세요.

계산 결과는 입력값 기준이며, 실제 지급 전 계약서와 관련 규정(지방계약법령·계약예규)으로 확인하십시오.
